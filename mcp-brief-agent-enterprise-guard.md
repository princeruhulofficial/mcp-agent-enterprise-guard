## Problem Statement
AI agents in production fail silently: they return empty results, call wrong tools, or violate policies without raising errors. Enterprise teams need a lightweight way to score agent reliability, enforce permission rules, and generate audit reports. Existing tools are either too heavy or focused on runtime monitoring of the MCP server itself. Founders validating AI products (Prevalid users) need a simple computation layer that works offline with their own logs.

## Core Tools (MCP Functions)

| Tool Name | Description | Input | Output |
|-----------|-------------|-------|--------|
| `score_agent_reliability` | Compute overall reliability score (0-100) from tool-call logs | logs (array of call objects), optional weights | score, breakdown, recommendations |
| `detect_silent_failures` | Flag calls that returned empty/null without error | logs | list of silent failures + rate |
| `evaluate_permission` | Allow/deny an agent action against a policy set | action, policy_rules | decision, matched rules, risk score |
| `generate_audit_report` | Produce human-readable governance report | logs + scores | markdown report + summary stats |
